Cómo crear un bot en Telegram

Sigue estos pasos para configurar tu bot y obtener las credenciales

1

Buscar a BotFather en Telegram

Abre Telegram y busca @BotFather en el buscador. Asegúrate de que sea el usuario verificado (tiene un check azul).

En el buscador escribe: @BotFather

2

Crear el nuevo bot

En el chat con BotFather, envía los siguientes comandos:

1. Escribe: /start
2. Luego escribe: /newbot
3. Sigue las instrucciones:
  • Escribe el nombre de tu bot (ej: Mi NMS Bot)
  • Escribe el username (debe terminar en bot, ej: mi_nms_bot)

BotFather te dará un mensaje de éxito con el HTTP API Token

3

Obtener el Token y Chat ID

Copia el HTTP API que te dio BotFather y sigue estos pasos:

1. Copia el token: 1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
2. Ingresa al link con tu token: https://api.telegram.org/bot<TU_TOKEN>/getUpdates
3. Envía un mensaje a tu bot:
  • BotFather te dará un link a tu bot (ej: t.me/tu_bot)
  • Haz clic en ese link y envía cualquier mensaje (ej: "Hola")
4. Actualiza la página del paso 2 y busca el "id":

En la respuesta JSON, busca "id" dentro de "chat". Ese es tu Chat ID.

{"ok":true,"result":[{"update_id":123,
  "message":{"message_id":1,
    "chat":{"id":123456789,...}}}]}

Tip: También puedes usar @getmyid_bot para obtener tu Chat ID más fácilmente.

4

Configurar en el sistema

Una vez tengas el Token y el Chat ID, colócalos en los campos correspondientes.

Haz clic en "Guardar Usuario" y recibirás un mensaje de confirmación en Telegram.
